# NetworkMapper

NetworkMapper is a Windows desktop app from DSR Technologies for discovering devices and building a live network map.

## Download

Get the Windows x64 ZIP from [Releases](https://github.com/Jakedoege/NetworkMapper/releases). Extract the whole folder and open NetworkMapper.exe. The v0.12 executable is unsigned.

## Features

- Local network discovery, device details, and live ping status
- Editable maps with saved views, device groups, and vendor icons
- Connection labels, annotations, and floor plans
- PNG and PDF export with an option to hide identifying labels
